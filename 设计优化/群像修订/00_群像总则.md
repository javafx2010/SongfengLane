## 一、这本书改成什么，不改成什么

不另起一部新书。人物、时间地基、身世账、三次质变的事件、结局「空而非悔」，一律沿用。

改的是**叙事主权**：不再让所有人给苏冬梅当镜子、台阶或工具。她仍是重要人物，是唯一必须同时向上一代和下一代交代的那根线，但不是唯一主角。林小满、许家平、苏德海、周惠兰、苏冬生、徐卫东、程雪见、丁桂宁、周念、马库斯、程永年，以及顾怀山、钱仲文、姜采薇、叶曼君、顾晓梅、陈九、周守青、温以苓、徐远山、苏嘉禾等，每人都要有独立欲望、行动线、代价、反转，以及与他人的对抗或博弈。

**苏冬梅的个人主题**（保留，不再独占书名下的全部面积）：

> 一个漂亮女人如何用她唯一愿意承认的资本，把自己一步步兑换成孤家寡人。

**全书的群像主题**（开写与改大纲时以此为书的秤，而不是只用林小满对照她）：

> 同一条巷子、同一本旧账里走出来的人，各用各的本钱兑换活路；他们互相算计、互相托住、互相错过——没有一个人只为别人的故事存在。

林小满仍是一把秤，但不是唯一的秤。许家平几乎举起又放下的那份自证、丁桂宁放在桌上的钥匙、苏冬生那一个「不」、程雪见买断后在停车场多坐的那一会儿、程永年隔着玻璃只问「那孩子怎么样」，都是秤。作者仍然不解释指针。

## 二、硬性保留（不因改群像而动摇）

1. 发布书名《松风巷的女儿》。时间地基：苏冬梅 1993 年生，正篇 2011—2038，尾声望至 2040；苏冬生 1999 年生；徐卫东 1995、程雪见 1996、苏嘉禾 2008、周念 2024。
2. 苏德海是她的亲爹（1996 年冬自己算明白，却再没抱过她），一辈子没被起诉、没坐过一天牢；她送进监狱的是弟弟的生父程永年，还以为自己在讨公道；徐远山不是她的父亲，只是一句闲话的影子。
3. **真相由读者拼完，作者不点破。** 正文不出现「支持亲生」「她其实是苏德海的女儿」这类结论句。
4. **弟弟到最后仍不知自己是谁的儿子。** 遗嘱只念「苏冬生」三个字，不写关系、不给理由；门缝复印件只证明有姓程的人给这个家打过钱，不是亲子鉴定。任何人口中、任何文件标题上，都不向他确认「程永年是你父亲」。他的人物核是「不问」。此条覆盖原设定里「遗嘱公开后他知道生父」的表述。与群像不冲突：他的完整弧线恰恰建立在「保住不问、仍失去家」上，不需要他得知答案。
5. 四个后代彼此不确认身份（苏嘉禾可隐约知道，但不说破）。程永年这个姓，与卷一第 5 章抽屉里的姓、与结尾信上的落款，必须是同一个字。
6. 苏冬梅视角里弟弟一律称「他」，她的视点中不出现「冬生」二字。别人的视点可以叫名字。
7. 不写「她终于明白」；不给幡然醒悟；结局是空不是悔；不写和解，不写有人在雨里抱住她；最后一页不许出现「如果」。
8. 家庭戏不靠吵架：真话在谁先动筷子、谁先签字、谁先不说话。敏感情节以行为与后果呈现，不写露骨细节；序幕童年戏保持非性描写；跨国恋情写成具体的人，不作族群化描述。
9. 三次质变的**事件**保留：举报信投出 → 报警（借公权力说谎）→ 立案并出庭（用制度伤及亲人）。章号随卷二起重编而改锚，不用旧 190/244 对外。
10. 卷一第 1–6 章已成稿的情节与章名，默认不动。必须改的只列定点清单（见 `02` 与 `03`），用后文群像补线。

## 四、视角与章类型

### 4.1 视点总则

1. 每章至多**两个**视点。段内只跟一个人，不写全知，不在段中偷换。两段之间不写「与此同时」，靠同一件东西、同一句话、同一场沉默接头。
2. **每章（尽量每卷每一章）至少两条人物线有推进。** 可以是双视点各推一条，也可以一个视点里完成自己的动作、同时把另一条线的博弈推进一步（对方必须有自己的要与怕，不能只当听众）。
3. 她的段落可以撒谎。别人的段落可以看见矛盾的动作，但**不点破、不下判词**，也不替读者做「其实她在利用你」的旁白。
4. 旁白只伺候当前视点人物能感到、能看见的世界，不得偷渡身世结论或「她走向毁灭」。
5. 上一代暗线只写他们当时以为自己在做什么，不写后来的道德判决。

### 4.2 章类型（开写时标注，可兼类）

| 类型 | 含义 | 写法 |
|---|---|---|
| **群像章** | 两条（偶尔三条里取两条）人物线在同一事件里同时推进 | 双视点或单视点交叉一场博弈；每条线都要有动作，不是「她做、别人看」 |
| **人物主场章** | 本章 A 情节是某个人自己的欲望与对手 | 苏冬梅可以是对手、证人、缺席者或短后段，但本章不是为了把镜头还给她 |
| **对位章** | 人物主场的一种：此人的眼睛看别人（可看她，也可看第三人） | 必须有独立戏剧动作与新信息；禁止「她的一天很寻常」 |
| **上一代暗线** | 1992–2005（或所标年份）上一代自己的博弈 | 由物件触发；每章只办一件旧事，且推动揭示或回收锚点；同一秘密不换景重讲 |
| **对峙 / 博弈章** | 当面或隔着制度的对抗 | 必须写清信息不对称、利益交换、联盟破裂或反将一军中的哪一种，以及谁先出手、谁付账 |
| **质变章** | 全书三次：投信、报警、立案并出庭 | 关键动作发生在动手者（苏冬梅）手上；第二视点可给共谋者、制度执行者或被伤到的人，**不规定她的篇幅比例** |

已取消的类型：

- 独立过渡章（不推事件、不设冲突、只设沉默）。一天、一顿饭、一次等待，只能作为事件章的尾场，尾场里仍须有一种静默冲突（信息差、关系冷却、该说的没说、该下的手没下）。
- 「她约 1/10 客串」与「她约 1/2–2/3 主线」两种配比。

卷一第 1–5 章前史、第 6 章巷口，已成稿，不按新类型回改结构。第 7 章起执行。

### 4.3 每卷配额（弹性，不是轮流）

- 取消「她的一章—对位章—上一代章」机械轮流。
- 每卷至少 **6 个非苏主场章**（人物主场或对位，含上一代）。主要人物在自己出场的卷里，至少有一场真正的主场（欲望、对手、代价都在）。
- 上一代暗线每卷 **2–4 章**，用来写苏德海、周惠兰、程永年、徐远山自己的棋，而不是只给女主提供氛围。
- 同一人物可以连续主场。不要为了「公平露脸」把一个人的一次博弈拆成三章空转。

## 五、博弈纪律（代替「六幕套在每个人头上」）

### 5.1 什么叫有戏，什么叫工具人

工具人：只在她需要一个对手、一个证人、一个对照时出现，自己没有要赢的东西。

有戏的人：本章或本卷能回答四句——

1. 他/她要什么（起点欲望，必须具体，不能是「活着」或「好」）？
2. 他/她看错了什么，或藏着什么（中途误判或秘密）？
3. 哪一次局面跟预想相反（反转）？
4. 跟谁对抗或交换，结果是什么（对抗结果：赢、输、两败、或赢了一样丢掉另一样）？

主要人物的这四句写在 `01_主要人物各自弧线.md`，各卷各章的落点写在 `02_各卷章节设计.md`。

### 5.2 每章必须有的东西

1. **至少一类冲突**，鼓励两类：利益（谁拿什么）、信息（谁不知道什么）、道德（谁该负责）、关系（谁被抛弃或谁先松手）。
2. **具体对手**：可以是人，也可以是制度、体检单、产权证、改过日期的合同、一通必须表态的电话。禁止「无冲突过渡章」。
3. **一场可命名的博弈**，四选一或组合：信息不对称、利益交换、联盟破裂、反将一军。开写时在章头用一句话写清「谁用什么换什么 / 谁瞒了谁 / 谁拆了谁的盟 / 谁把谁的招还回去」。
4. **章尾一个具体的新问题**（「这张纸她会不会用」），不要抽象（「她的心会不会软」）。
5. 冲突不靠吵架。家庭戏尤其如此。

### 5.3 卷与卷咬合，不是短篇集

每人的弧线必须跨卷咬合：上一卷欠的手，下一卷要付或再下一次注。禁止某卷突然插入一个「某某的一天」而此前此后都不再见。`01` 里每个人都标明咬合的卷次；写某一卷时先核对谁在本卷必须推进一格。

苏冬梅的个人螺旋（保研构陷 → 身体上位 → 弃子远走 → 异国沉沦 → 包装骗婚 → 婚内驱逐 → 梭哈 AI）仍可作为**她自己的**递降，用来检查她有没有先得手再付账。不要把这六步派发给林小满、许家平或程雪见。

### 5.4 对手层级（她的线仍升级，别人的线按自己的战场）

她的对手可仍大致按：同学 → 主管 → 派系 → 情人与身体 → 婆家 → 丈夫与制度 → 亲人与资本。不要跳级提前用公权力打同学，也不要在卷七再打一轮宿舍名誉。

其他人按自己的战场升级，例如：林小满是房东/条款/舆论站队；许家平是母亲的「你要争」与律师的「舆论先判」；程雪见是程序与父亲留下的洞。

## 九、开写检查清单（第 7 章起可复制）

```
- [ ] 本卷年份、相关人物年龄已与年表核对
- [ ] 章类型已标明：群像 / 人物主场 / 对位 / 上一代暗线 / 对峙博弈 / 质变（可兼类）
- [ ] 视点不超过两个；没有用配比去「补她的篇幅」或「把她减到客串」
- [ ] 至少两条人物线有推进；两条都有自己的要与怕
- [ ] 有可命名的博弈（信息差 / 交换 / 联盟破裂 / 反将一军）
- [ ] 有对手；至少一类冲突；章尾有一个具体的新问题
- [ ] 有动作，无「她终于明白」句
- [ ] 她的视点未出现「冬生」二字
- [ ] 未泄露鉴定结论、未把徐远山写成生父、未向弟弟确认生父
- [ ] 本章不是上一卷已演过的会议、门缝、一巴掌、遗嘱宣读的重拍
- [ ] 若涉及主要人物，其动作能在 01 的弧线上向前推一格，而不是只为映衬别人
- [ ] 卷五起涉及她的坐、走、亲密或出行时，痔疮线有具体动作（坐不住、软垫、回避亲近、不说出那个词），没有写成笑话

```

卷末另核：本卷应推进的主要人物是否都动了一格；有没有无冲突空章；与上一卷有没有重拍；四本账或其持有者是否至少露一次面（只出现，不解释）。

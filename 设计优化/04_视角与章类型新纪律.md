# 《松风巷的女儿》设计优化·04 视角与章类型新纪律

> 开写每一章前读一遍。本文件替代原 `设定/04` 中「1/10 配比」「每章不少于两万字」「过渡章不设冲突」「三线机械轮流」四条；其余原纪律（不写「她终于明白」、每章至多两视点、家庭戏不吵架、真相由读者拼等）仍然有效。
> 第 1—6 章已成稿，不按新配比、新章长回改。第 7 章起严格执行。

---

## 一、视点总则

1. 苏冬梅是核心女主。读者主要跟着她的手、她的嘴、她的兑换走。别人的眼睛用来付账、露出破绽、称一次秤，不是用来把她写成客串。
2. 每章至多**两个**视点。段内只跟一个人，不写全知，不在段中偷换。
3. 两段之间不解释、不写「与此同时」。靠同一件东西、同一句话、同一场沉默接头。
4. 她的段落可以撒谎。别人的段落可以看见矛盾的动作，但**不点破、不下判词**。
5. 旁白只伺候当前视点人物能感到、能看见的世界（巷子的热、桌面的油、群里的红点），**不得偷渡**：「其实她是亲女」「读者将来会知道」「她终于开始走向毁灭」。
6. 苏冬梅视点里，弟弟只称「他」，不出现「冬生」。别人的视点可以叫他的名字。
7. 全书不许出现「她终于明白」「她意识到」「她开始反思」。明白只能做成动作：把照片放回去，把抽屉推紧，把钥匙放在桌上，把汤倒回锅里。
8. 上一代暗线不写后来的道德判断，只写他们当时以为自己在做什么。

## 二、章类型与配比

### 2.1 主线章（默认，约占每卷六成或以上）

- 视点：她占 **1/2 至 2/3**；其余可给一个配角，前置或后置均可。
- 必须发生：本卷兑换或付账的一个具体动作（谁开口、谁沉默、谁递东西、谁签字、谁松手）。
- 她的动作不配心理分析，但动作本身要完整，不能只在章尾露脸。
- 适合：见面、交换、构陷、上床前后那句话、报警、交名单、路演、抵押。

### 2.2 对位章

- 视点：全章一个人。她只以「被看见」的方式出现，或本章根本等不到她。
- 每卷 **3—6 章**（卷一已有 8 章，维持，不再增加）。同一人物每卷至多一个独立对位章。
- 必须有独立戏剧动作：这个人自己的要与怕，不是在候场。
- 必须带来新信息或新代价（一笔未发出的微信、一句「我没看见」、一把放在桌上的钥匙）。只写「她的一天很寻常」则并回主线尾场。
- 不进入她的内心。可用「她那天把扣子扣到最上面」这类看见。
- 卷末「他人之眼」用对位章写法。

### 2.3 上一代暗线章

- 视点：1992—2005 年（或所标注年份）的上一代一人。她若不在场，不要硬切她。
- 每卷 **2—3 章**。每章只办一件旧事，并至少推动四层揭示或回收一件锚点。
- 由物件触发：红围巾、坐垫、喇叭、鉴定、车票、信、账本。
- 同一秘密不换场景重讲一遍。真鉴定的文字结论，不要借暗线在卷一宣读完。

### 2.4 质变章（全书三章，特殊）

- 视点：她不少于 **2/3**，可以没有第二视点。
- 三次事件：举报信投出；报警；立案并出庭。手、邮筒、笔、门口的风，必须在她的视点里完成。
- 第一次允许手抖；后两次写「不抖」只需一个动作，不要自我评价。

### 2.5 卷末她的塌陷

- 以她的视点为主。失去本卷押上的本钱，写安静：电话不响，旗袍没带，屏幕归零，房子太大。
- 转折不是顿悟，是又一次下注的开始，或下注之后的空。

### 2.6 已取消的类型：独立过渡章

一天、一顿饭、一次等待、一次卸妆，作为**事件章的尾场**来写，保留沉默。尾场里仍须有一种静默冲突（信息差、关系冷却、该说的话没说）。不要再单独立章，也不要再写「本章不设冲突」。

卷一已标为过渡、尚未成稿的第 12、30 章：若保留章名，按「短主线 / 短暗线 + 静默冲突」写，不按空章写。

### 2.7 卷一前史例外

第 1—5 章（已成稿）允许家庭群像、她的童年限知与父母视点交替，不受「她占 1/2」下限约束。第 6 章已成稿，保持原结构。

## 三、章长

| 类型 | 第 7 章起的正文 |
|---|---|
| 主线章 | 8,000—12,000 字 |
| 对位章、上一代暗线 | 6,000—10,000 字 |
| 质变章、卷末双章 | 12,000—15,000 字（可到上限，不要为了凑 2 万注水） |
| 第 1—6 章 | 已写体量保持，不压缩、不补水 |

计数不含元数据头与检查清单。不许用心理独白、景物重复、菜单式旁白凑字。对话再多，视点仍是那一个。

---

## 四、冲突、对手、章尾

原纪律收紧如下，取消与过渡章的矛盾：

1. 每章至少一类冲突，鼓励两类。四类仍是：利益（谁拿什么）、信息（谁不知道什么）、道德（谁该负责）、关系（谁被抛弃）。
2. 每章必须有对手。对手可以是人，也可以是制度、体检单、产权证、一份改过日期的合同、一张不响的脸。
3. 每章结尾留下一个新问题，让下一章非处理不可。问题须具体（「这张纸她会不会用」），不要抽象（「她的心会不会软」）。
4. 冲突不靠吵架。家庭戏尤其如此：谁先动筷子，谁先签字，谁先不说话，谁把最后一块肉夹给谁。
5. 对手层级仍随卷升级：同学 → 主管 → 派系 → 情人与身体 → 婆家 → 丈夫与制度 → 亲人与资本。不要跳级提前用「公权力」打同学，也不要在卷七再打一轮「宿舍名誉」。

## 五、六幕在写作中的用法

开卷先在大纲上标出六幕起止，再写章。检查三句：

1. 本卷是否先写清「得手」（变现），再写「付账」（嫌弃与塌陷）？若先塌后得，停笔改序。
2. 本卷「关系起点」是不是又换了一批演员演同一场？允许同构，不允许把上一卷的会议、门缝、一巴掌重拍。
3. 卷末转折是不是「又一次下注」而不是「她想通了」？想通了就作废。

卷一幕一可以是前史与出走，顾怀山从第 7 章进。卷七幕一是她与最后一笔本钱 / AI 局的关系，不是再找一个男人。

---

## 六、话语线与秤，在章内怎么落

1. 落笔前看 `01` 第六节：本卷只准把那一句漂亮话用满。发现自己在用后卷的句式（例如卷二就说「我是家暴受害者」），删掉，换回本卷的句子。
2. 漂亮话要有听众（HR、亲友群、律师、投资人、海关、婆婆）。自言自语不算话语线。
3. 林小满若在本卷露面，必须做一个动作，不能只被提起。动作清单见 `01` 第七节。她不说漂亮话，也不替作者劝世。
4. 对位章若写林小满，全章跟她的手和账，苏冬梅只被看见或错过。

---

## 七、伏笔与泄露的章内红线

写任何涉及身世、鉴定、遗嘱、徐远山的场面，过这五条：

1. 正文不出现「支持亲生」「她其实是苏德海的女儿」这类结论句（设定里作者知道即可）。
2. 不把徐远山写成确定的生父，不把出账簿宣读成血缘证明。
3. 不让弟弟在任何人口中得知「程永年是你父亲」。遗嘱只念名字。
4. 四本账每卷至少露一次面，只出现，不解释。
5. 橘子在 2038 年重逢之前不要出现。钥匙只跟卷六丁桂宁那一次离开。

追问七次：必须母女同场（第七次母亲已不在，问的是遗物），必须是日常动作，她不提高声音。不要把追问塞进邻居、孩子、海关官员的对位章里。

## 八、每章开写检查清单（可复制进章文件头）

```
- [ ] 本卷年份、女主年龄、弟弟年龄已与年表核对
- [ ] 章类型已标明：主线 / 对位 / 上一代暗线 / 质变 / 卷末塌陷 / 卷末他者之眼
- [ ] 视点不超过两个；主线章她的篇幅在 1/2—2/3（质变章 ≥2/3；对位/暗线她不进内心）
- [ ] 章长落在对应区间，没有为凑字重复描写
- [ ] 有对手；至少一类冲突；章尾有一个具体的新问题
- [ ] 有动作，无「她终于明白」句
- [ ] 她的视点未出现「冬生」二字
- [ ] 本卷话语阶梯的那句话，如该用已用，未偷用后卷句式
- [ ] 未泄露鉴定结论、未把徐远山写成生父、未向弟弟确认生父
- [ ] 若本卷该出现林小满，已落到动作（或已安排在本卷另一章，本章不硬塞）
- [ ] 须露面的线索物件已按本卷大纲出现，且不加解释
- [ ] 本章不是上一卷已演过的会议、门缝、一巴掌、遗嘱宣读的重拍
```

成稿后把「写作状态」改为已完稿。章名可微调，锚句画面不能丢。

## 九、卷末校验清单

```
- [ ] 六幕次序仍是得手在前、付账在后
- [ ] 本卷押上的本钱已在塌陷中失去（学位 / 职位 / 国内积累 / 身体与生育 / 婚姻的里面 / 家与体面 / 最后一笔钱）
- [ ] 有「她的塌陷」与「别人的眼睛」，且后者不解释她
- [ ] 林小满本卷的动作已完成
- [ ] 四本账或其持有者至少露一次面
- [ ] 追问本卷一次已落在母女（或遗物）场，而非错章
- [ ] 话语线本卷那一句已用脏
- [ ] 她又失去至少一个还能打电话的人（或已经无号可拨）
- [ ] 与上一卷对照：没有重拍同一事件
- [ ] 年龄、科技器物、媒介名称没有穿越
```

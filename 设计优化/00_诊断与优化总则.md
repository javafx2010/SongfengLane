## 一、硬性保留（不改主题，不另起一部新书）

1. 发布书名《松风巷的女儿》；女主苏冬梅，1993 年生。
2. 一句话主题：**一个漂亮女人如何用她唯一愿意承认的资本，把自己一步步兑换成孤家寡人。**
3. 全书的秤：林小满不说漂亮话，只把「人得先把自己当人」做成动作；苏冬梅把话说得滴水不漏，生活却一次次缩回旧路。作者不解释指针。
4. 七卷同构递降螺旋：保研构陷 → 身体上位 → 弃子远走 → 异国沉沦 → 包装骗婚 → 婚内驱逐 → 梭哈 AI → 孤家寡人。
5. 四条线并行：关系 / 生存 / 堕落 / 话语。话语线的锋刃仍是——话越漂亮，事越脏。
6. 时间地基：苏冬梅 1993 年生，正篇 2011—2038，尾声望至 2040，年表可望至 2041。弟弟苏冬生 1999 年生。年龄基准维持原表（徐卫东 1995、程雪见 1996、苏嘉禾 2008、周念 2024）。
7. 结局是「空」而非「悔」：不安排幡然醒悟，不写和解，不写有人在雨里抱住她；最后一页不许出现「如果」；全书不许出现「她终于明白」。
8. **弟弟身世到最后自己仍不知**——他可以收到一笔来路不明的钱、签一份不解释的协议，但任何人口中、任何文件标题上，都不向他确认「程永年是你父亲」。他的人物核是「不问」。此条覆盖原设定 v2「遗嘱公开后他知道生父」的表述（见第三节第 8 条）。
9. v3 核心反讽不动：苏德海是她的亲爹（1996 年冬自己算明白，却再没抱过她），一辈子没被起诉、没坐过一天牢；她送进监狱的是弟弟的生父程永年，还以为自己在讨公道；徐远山不是她的父亲，只是一句闲话的影子。
10. 三次质变的**事件**保留（具体章号随卷二起重新编号而改锚，见 `01`）：举报信投出 → 报警（借公权力说谎）→ 立案/出庭（用制度伤及亲人）。
11. 真相由读者拼完，作者不点破。程永年这个姓，与卷一第 5 章抽屉里的姓、与结尾信上的落款，必须是同一个字。四个后代彼此不确认身份（苏嘉禾可隐约知道，但不说破）。
12. 苏冬梅视角里弟弟一律称「他」，全书她的视点中不出现「冬生」二字。
13. 家庭戏不靠吵架：真话在谁先动筷子、谁先签字、谁先不说话。敏感情节以行为与后果呈现，不写露骨细节；序幕童年戏保持非性描写；跨国恋情写成具体的人，不作族群化描述。
14. 卷一第 1—6 章已成稿的情节与章名，默认不动（例外见第七节「必须回改卷一」）。

## 三、主要诊断（必须处理的结构性问题）

### 1. 视角纪律自我打架，女主会被写成客串

原宪法一方面把苏冬梅定为「核心女主」「全书唯一主视角」，另一方面在 `设定/04`、`大纲/00` 规定：**她不再是核心人物，每章只占约 1/10，其余 ≥9/10 写别人**；再叠加「每章不少于两万字」。这会把一本女频都市/原生家庭长篇写成「群像展览，女主每章最后露个脸」。

后果：主线稀释，读者跟丢兑换与黑化的身体感，对照秤（林小满）也会被淹没在众多「别人的一天」里。群像独立成立是好设计，1/10 一刀切不是。

**改法**：见 `01` 与 `04`。她仍是核心女主与情感主锚；默认章她的视点占一半到三分之二；对位章、上一代暗线章才把舞台整场交给别人；序幕前史（已写的第 1—5 章）维持家庭群像，不回改配比。

### 2. 168 扩到 272，再配「每卷同一套六幕 + 过渡/对位注水」，机械且会空

原 168 核全部保留，新章靠三类增量：「一章一事拆成三章」、每卷 4—6 个不推事件的过渡章、对位章加到卷七 16 个。六幕道德次序（先得手、后付账）是全书骨架，应当留；「每卷都 6/6/6/6/6/6 或等额扩写」不是骨架，是模版疲劳。

再乘「每章 ≥2 万字」，272 章约 544 万字，既难写完，也几乎必然注水。过渡章「不设冲突」又与「每章至少两类冲突、一个对手」直接矛盾。

**改法**：目标约 **216 章 + 短尾声**（卷一锁定 36，卷二至卷七共减约 56 章）。砍的是独立过渡章、同事件拆三段、以及卷七对卷六的重拍；不砍三次质变、四本账收网、结局动作。章长改为可执行的区间，见 `01`。

### 3. 卷六与卷七把同一组家庭戏写了两遍

以下事件在两卷各自成套出现，是当前设计最大的「重拍」漏洞：

| 事件 | 卷六 | 卷七 |
|---|---|---|
| 「爸这辈子抱过你吗」 | 第 205 章 | 第 233 章 |
| 门缝塞复印件 | 第 206 章 | 第 234 章 |
| 丁桂宁离开 | 第 207 章 | 第 235 章 |
| 母亲一巴掌 | 第 211 章 | 第 236 章 |
| 合同 / 改期 / 递材料或立案 | 第 218—221 章 | 第 242—244 章 |
| 「你和你妈一样」 | 卷五第 177 章已是本卷塌陷；卷六说明与年表 2033 又写一次 | 第 241 章再录一次音 |

根子在 v3 把程永年去世从约 2032 改到 2037 后，遗嘱、递材料、拆弟婚的章表没有一次重排干净。年表 2033 仍出现「听遗嘱宣读」（人还活着、尚未入狱），卷六第 222 章细纲甚至写成程永年已去世——与「2037 年死在疗养院」直接打架。

**改法**：每件事只发生一次。第三层「用」（身世牌、门缝、拆婚、一巴掌、整理并递出材料）全部放在卷六收束；卷七从「镜子 / 拆迁余波 / AI 起步」进入，第三次质变落在**立案与出庭**，不再重演门缝与一巴掌。遗嘱宣读只在 2037 年程永年死后。详见 `03`。

### 4. 黑化台阶清楚，但质变锚点、话语线、物件有的不够尖，有的会提前泄露或用重

- 三次质变事件本身够锐，可执行时被「拆成三章」和卷六十卷七重拍稀释。
- 话语线有材料（「我不是那种人」「我被骚扰了」「海外精英」「家暴受害者」），但缺少「每卷一句、越来越脏」的强制阶梯，写起来容易原地打转。
- 「追问七次」是好母题，可现有章锚大量落在对位章或章名不符的章上（第一次锚在第 17 章《名额公示》，而退学在第 27—28 章）。
- `连续性/02` 仍残留 v3 之前的句子：把「她的出身是一个跑长途的」写成她拒绝面对的真相。按现行设定，徐远山**不是**生父。这条不改，后文会写错结局。
- 鉴定「支持亲生」若在卷一用苏德海内心或旁白直接宣读，全书最大反讽开篇就被作者点破，与「读者拼完」冲突。
- 橘子是 2038 年重逢的锚点，却在卷七第 255 章病房里提前摆上桌，会把收网物象用旧。
- 第 271 章已是公交站，尾声又是公交站；第 272 章墓园门口还重复「走两条街再蹲下」（与商场重逢同一动作）。

### 5. 人物体系过载，对照秤没有每卷落到动作上

命名角色三十人上下。功能重叠：温以苓 / 褚衡都做包装；韩秋实 / 江晚棠都承担卷一话语讽刺；顾晓梅与林小满都是巷口道德对照；顾小玫、卷四「更年轻的女人」、周念，三重「年轻的她」。岑青桐被误放进「女主群四位」表。

更致命的是：**林小满作为全书的秤，章表里在第 24 章热汤之后基本失踪**，只在尾声「开了间小饭馆，见过她一次，没认出来」。顾晓梅标注「卷二接职场线」，卷二章表并无她。秤若不称，七卷螺旋就只剩女主自己摔，读者没有刻度。

### 6. 时间、生理、科技有几处经不起推敲

- 2004 年苏德海出国后「只出现三处」，却另有 2008 年「你是苏家的」、2031 年病床边见面——出现点必须补全，不能口头说三处、正文写五处。
- 卷四第 125 章已「丧失生育能力」，第 134 章又早产得周念，生理顺序不成立。
- 年表 2019 年苏万山第一次中风，卷五却把「祖父的中风」写成新事件，卷二章表没有接应。
- 卷七 2033—2038 的「梭哈 AI」：女主无技术背景，2033 年再以「发现风口」入场会显得外行。应写成她把「人设与漂亮话」卖给已经拥挤、开始退潮的应用层，讽刺才站得住。
- 徐卫东「早知道她是谁」与 v3「徐远山不是生父」冲突，须改成「他认错了亲」。

### 7. 命名与工程口径不一致

README 目录树仍写 `锦绣前程/`、`正文/`；总纲标题仍是《锦绣前程》；写作流程指向 `正文/卷X/`。云端实际是 `Create/松风巷的女儿/章节/`，另有 `架构设计/`、`封面/`、`.git`。`_gen_stubs.py` 注明重跑会覆盖正文，危险，须在流程里标红。

### 8. 「弟弟知不知道」在原件内部就不统一

`设定/03`、`设定/04` 写「到最后不知道自己是谁的儿子」；`设定/02`、`尾声`、`连续性/02`、来源说明 v2 写「遗嘱公开后他知道程永年是父亲」。本稿按硬性保留第 8 条，统一为**仍不知**，并给出不泄露的遗嘱写法（只写名字、不写关系；现场无人解释；他不问）。

## 四、优化原则（以后凡有争论，先看这一节）

1. **先保住那一句话，再动结构。** 任何增章、对位、暗线，都要能称一次「兑换」或「孤」，否则并掉。
2. **螺旋是同构，不是重拍。** 七卷可以走同一套六幕道德次序；不允许把上一卷已经付过的账再演一遍。
3. **群像为她的主线付账，不为了群像而群像。** 别人的一天必须独立成立，也必须把代价还到她的兑换上。
4. **减的是水，不是网。** 四本账、八件锚点、三次质变、结局四个动作、2038 年那袋橘子，一件不删；删的是重复场面与「起因—过程—后果」机械拆章。
5. **作者比读者早知道，正文比作者少说。** 尤其生父、假鉴定、遗嘱，设定里写死，正文里只给动作和物件。
6. **卷一已写的，能不改就不改**；卷二以后的设计，一次性改准，避免边写边补丁。
7. **女频的节奏可以要，救赎不要。** 「爽」只用来带过动作与反击的手感，结算时仍是一个人。

## 七、必须回改卷一的条目（仅当已写正文已经踩雷）

本次**未通读**第 1—6 章正文（第 5 章约 75 KB，第 1 章约 59 KB）。下面是开写第 7 章之前必须完成的自检；**只有确已违规，才动第 1—6 章**，并且是定点改，不是重写故事。

1. **生父结论是否被作者说破。** 若第 1—5 章已用苏德海内心、旁白或化验单正文写出「支持亲生 / 1996 年他算明白她是亲女」这类结论句，须改成只写动作：两张纸取出又放回、手抬到一半没有抱、一份纸锁进抽屉、桌上摊开的是「两个都不是」的那份。结论留给读者后文去拼。
2. **是否把徐远山写成（或暗示成确定的）生父。** 按 v3，他不是。闲话、薄信、三下喇叭可以有，叙述者不得宣布他是父亲。
3. **苏冬梅视点是否出现「冬生」二字。** 有则改称「他」。

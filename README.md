# 《松风巷的女儿》小说编写工程

> 长篇小说《松风巷的女儿》写作工程。全书七卷 272 章 + 尾声，跨度 2011—2038（尾声望至 2040）。
> 发布书名：《松风巷的女儿》（原定名《锦绣前程》，因平台重名弃用；女频·都市生活/原生家庭向，见 `资料/书名与简介.md`）。
> 设定来源：ima 个人知识库笔记《锦绣前程》（2026-11-16 读取，见 `资料/来源说明.md`）。

## 一句话简介

一个漂亮女人如何用她唯一愿意承认的资本，把自己一步步兑换成孤家寡人。核心女主苏冬梅（1993年生），七卷同构递降的螺旋：保研构陷 → 身体上位 → 弃子远走 → 异国沉沦 → 包装骗婚 → 婚内驱逐 → 梭哈AI → 孤家寡人。

## 写作流程（每章照此执行）

1. **开卷前**：读 `设定/01`（本卷年份/年龄/四条线侧重）→ `连续性/01` 年表核对该卷时间线 → `大纲/卷X.md` 读幕结构与"必须露面的线索物件"。
2. **开章前**：打开 `正文/卷X/第NNN章_*.md`，读元数据头（幕、类型、冲突六列），过一遍写作检查清单。
3. **成稿后**：清单逐项打勾；把"写作状态"改为"已完稿"；如章名微调，保留锚句画面不变。
4. **卷末**：对照该卷大纲的"幕级校验"与"卷末双章"要求自查。

## 硬性纪律（摘要，全文见 设定/04）

- 六幕排布不可挪动：关系起点→资本变现→裂痕→被嫌弃→塌陷→卷末转折。
- 不写心理独白，只写动作；全书不许出现"她终于明白"。
- 每章至少两类冲突、一个对手，结尾留一个新问题。
- 真相由读者拼完，作者不点破；弟弟到最后不知道自己是谁的儿子。
- 苏冬梅视角里弟弟一律称"他"，全书不出现"冬生"二字。
- 不给女主幡然醒悟；她的黑化终点不是悔，是空。
- 家庭戏不吵架：真话在谁先动筷子、谁先签字、谁先不说话。
- 最后一页不许出现"如果"两个字。

## 三次质变（全书刻度）

1. 第16章 举报信投出去（卷一）——从"想活得更好"到"可以毁掉别人"
2. 第190章 报警（卷六）——从"说谎"到"借公权力说谎"
3. 第244章 立案（卷七）——从"借制度伤人"到"用制度杀亲人"

## 工程维护

- 章节文件由 `资料/_gen_stubs.py` 从大纲章表自动生成（幂等：重跑会覆盖正文区外的元数据；**已在文件内写的正文会被覆盖，重跑前请先备份或改造脚本跳过含正文的文件**）。
- 大纲章表是唯一事实来源：改章节设定先改 `大纲/卷X.md`，再同步正文文件元数据。
- 若 ima 端原笔记更新，先核对 `资料/来源说明.md` 所列映射再合入本工程。
